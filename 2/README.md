# 医疗设备管理系统

## 项目简介

医疗设备管理系统是一套面向医疗机构的**全栈设备生命周期管理平台**，采用前后端分离架构设计。系统覆盖设备从采购建档、日常巡检、故障维修、质量控制到报废的全流程管理，帮助医院实现设备的数字化、智能化管理，提高设备利用率，降低运维成本，保障医疗安全。

### 核心价值

- **全生命周期管理**：覆盖设备从采购到报废的完整生命周期
- **智能预警提醒**：巡检到期、保养提醒、合同到期、高风险设备预警
- **数据驱动决策**：多维度统计分析，为设备采购和维护提供数据支撑
- **精细化成本管控**：维修成本、配件消耗、停机时间精准统计

## 核心功能模块

### 1. 设备档案管理
- 设备基础信息台账（名称、型号、编号、厂家、序列号等）
- 设备状态管理（正常使用、维修中、停机、报废、校准中、质控中）
- 风险等级评估（高风险、中风险、低风险）
- 设备归属科室、位置信息管理
- 保修信息、维护记录管理

### 2. 巡检计划管理
- 巡检计划配置（日/周/月/季/年周期）
- 检查项目自定义配置
- 巡检任务自动生成（定时任务调度）
- 任务日历视图展示
- 巡检任务执行与记录
- 异常情况上报与处理建议

### 3. 维修工单管理
- 维修工单全流程（报修→派单→维修→验收→归档）
- 故障等级划分（紧急、一般、轻微）
- 维修人员智能分配
- 维修进度实时追踪
- 配件更换记录与库存扣减
- 停机时长自动统计
- 维修成本核算

### 4. 质控记录管理
- 质控计划制定
- 质控标准与检查项目配置
- 质控数据录入与结果判定
- 不合格设备自动锁定
- 偏差处理与复检流程
- 质控趋势分析

### 5. 校准记录管理
- 校准计划与周期管理
- 校准机构与人员管理
- 校准证书编号与有效期管理
- 校准项目与偏差值记录
- 下次校准日期自动提醒
- 校准结果统计分析

### 6. 维保合同管理
- 维保合同信息管理（维保/维修/校准合同）
- 合同金额与付款状态跟踪
- 合同有效期管理
- 到期自动提醒（提前30天预警）
- 供应商与联系方式管理

### 7. 配件库存管理
- 配件基础信息管理
- 库存数量与最低库存预警
- 出入库流水记录
- 配件更换关联维修工单
- 库存盘点与报表

### 8. 停机记录管理
- 停机类型分类（故障停机、维护停机、校准停机、其他）
- 停机时长精确统计
- 停机原因分析
- 停机损失估算
- MTBF（平均无故障时间）分析

### 9. 科室管理
- 科室树状结构管理
- 科室负责人与联系方式
- 科室设备统计
- 按科室数据权限控制

### 10. 用户与权限管理
- 用户信息管理
- 角色权限配置（系统管理员、设备管理员、维修工程师、质控人员、科室主任）
- 基于角色的权限控制（RBAC）
- JWT Token 认证

### 11. 统计分析报表
- 设备状态分布统计
- 维修工单趋势分析
- 故障类型与频率分析
- 维修成本统计
- 高风险设备看板
- 设备利用率分析
- 自定义报表导出

### 12. 风险预警看板
- 高风险设备清单
- 待处理任务预警
- 合同到期提醒
- 校准到期提醒
- 库存不足预警
- 质控不合格设备警示

### 技术架构说明

#### 前端技术栈
- **框架**: Vue 3.4.x + Composition API
- **构建工具**: Vite 5.0.x
- **UI 组件库**: Element Plus 2.4.x
- **状态管理**: Pinia 2.1.x
- **路由管理**: Vue Router 4.2.x
- **图表库**: ECharts 5.4.x
- **HTTP 客户端**: Axios 1.6.x
- **CSS 预处理器**: Sass 1.69.x

#### 后端技术栈
- **核心框架**: Spring Boot 3.1.8
- **ORM 框架**: MyBatis Plus 3.5.8
- **安全框架**: Spring Security + JWT 0.12.6
- **接口文档**: Knife4j 4.5.0 (OpenAPI 3)
- **任务调度**: Spring Scheduler
- **Excel 处理**: EasyExcel 3.3.4
- **状态机**: 自研设备状态机 + 工单状态机

#### 数据存储
- **关系型数据库**: MySQL 8.0+（业务数据持久化）
- **缓存数据库**: Redis 6.0+（会话管理、数据缓存、热点数据）

#### 部署架构
- **前端**: Nginx 静态资源服务 + 反向代理
- **后端**: JAR 包独立部署或 Docker 容器化部署
- **数据库**: 主从部署（建议生产环境）

## 快速开始

### 第一步：环境准备

确保你的开发环境已安装以下软件：

| 软件 | 版本要求 | 验证命令 |
|------|----------|----------|
| JDK | 17+ | `java -version` |
| Maven | 3.8+ | `mvn -version` |
| MySQL | 8.0+ | `mysql --version` |
| Redis | 6.0+ | `redis-server --version` |
| Node.js | 18+ | `node -v` |
| npm | 9+ | `npm -v` |

### 第二步：数据库初始化

```bash
# 1. 启动 MySQL 和 Redis 服务
# 2. 创建数据库并执行初始化脚本
mysql -u root -p < backend/src/main/resources/sql/init.sql
mysql -u root -p medical_device < backend/src/main/resources/sql/data.sql
```

### 第三步：启动后端服务

```bash
# 进入后端目录
cd backend

# 修改数据库和 Redis 配置
# 编辑 src/main/resources/application.yml

# 启动服务
mvn spring-boot:run
```

后端启动成功后，访问：
- 接口文档: http://localhost:8080/api/doc.html
- 健康检查: http://localhost:8080/api/actuator/health

### 第四步：启动前端服务

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端启动成功后，访问：
- 系统首页: http://localhost:5173

## 系统特性

### 安全特性
- JWT Token 无状态认证
- Spring Security 权限控制
- 基于角色的权限控制（RBAC）
- 密码加密存储（BCrypt）
- 接口请求参数校验
- 统一异常处理

### 业务特性
- 设备状态机：严格控制设备状态流转
- 工单状态机：规范维修流程
- 定时任务：自动生成巡检任务、合同到期提醒
- 逻辑删除：数据安全不物理删除
- 乐观锁：防止并发更新冲突
- 数据权限：按科室隔离数据

### 性能特性
- Redis 缓存热点数据
- 数据库连接池优化（HikariCP）
- MyBatis Plus 分页查询
- 异步任务处理
- 静态资源 CDN 加速（生产环境）

# 实验室样品登记与检测系统

基于 Python + PySide6 + SQLite 开发的桌面应用，用于实验室样品登记、检测记录管理和报告生成。当前版本：**v2.0.0**

## 功能特性

### 核心功能（第一轮）
- **样品管理**: 样品登记、编辑、删除、查询
- **检测记录**: 检测项目录入、结果记录、状态跟踪
- **状态流转**: 待检测 → 检测中 → 检测完成 → 报告已生成 → 已归档
- **附件管理**: 支持上传、下载、删除附件，文件丢失检测
- **报告导出**: 支持 Excel 和 PDF 格式检测报告
- **数据备份**: 数据库备份与恢复
- **操作审计**: 所有修改操作留痕，可追溯
- **统计概览**: 样品数量统计、按状态分布
- **搜索筛选**: 支持按关键词、状态、日期范围筛选

### 新增功能（第二轮 v2.0）
- **完善的状态流转规则**
  - 明确 6 种状态之间的合法切换路径
  - 待检测 ↔ 检测中 → 检测完成 → 报告已生成 → 已归档
  - 各状态均可切换至"已作废"终止流程
  - 界面实时显示状态描述和可切换选项
  - 非法状态切换自动拦截并给出清晰提示

- **检测结果修改留痕**
  - 修改检测结果时强制填写修改原因
  - 自动记录所有字段变更历史（原值、新值）
  - 记录修改时间、操作人、修改原因和备注
  - 提供"修改记录"标签页，支持按检测记录、样品查询
  - 所有变更永久保存，保证留痕可查

- **增强的附件管理**
  - 附件预览入口：支持图片、文本、PDF 等格式在线预览
  - 缺失附件重新绑定：文件丢失后可选择新文件重新关联
  - 附件路径校验：自动检查文件存在性、大小限制（最大 100MB）
  - 异常提示：文件缺失、格式不支持时给出明确提示
  - 附件统计：总数量、总大小、缺失数量统计

- **改进的报告导出模板**
  - 报告内容包含 5 个完整部分：
    1. 样品基础信息（编号、名称、来源单位、接收时间等）
    2. 检测项目及结果（检测人员、结果值、标准值、是否合格）
    3. 状态流转记录（所有状态变更历史）
    4. 检测结果修改记录（所有修改历史）
    5. 附件清单（文件名、大小、上传人、上传时间）
  - 支持 Excel 和 PDF 两种格式

- **完善的统计概览**
  - 9 个统计卡片：总数、待检测、检测中、检测完成、今日新增、完成率、异常、附件、已报告
  - 各状态数量及占比计算
  - 检测完成率实时统计
  - 异常样品数量统计
  - 检测人员工作量排名

## 状态流转规则

```
                        ┌──────────┐
                        │  已作废  │
                        └────▲─────┘
                             │
┌──────────┐  ┌──────────┐  │  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ 待检测   │↔│ 检测中   │─┼─▶│ 检测完成 │─▶│报告已生成│─▶│  已归档  │
└──────────┘  └──────────┘  │  └──────────┘  └────▲─────┘  └──────────┘
                             │                     │
                             └─────────────────────┘
```

| 当前状态     | 允许切换到的状态               | 状态描述                     |
|--------------|--------------------------------|------------------------------|
| 待检测       | 检测中、已作废                 | 样品已登记，等待开始检测     |
| 检测中       | 待检测、检测完成、已作废       | 检测人员正在进行检测         |
| 检测完成     | 检测中、报告已生成、已作废     | 所有检测项目已完成，可生成报告 |
| 报告已生成   | 检测完成、已归档、已作废       | 检测报告已生成               |
| 已归档       | 报告已生成                     | 样品已归档，流程结束         |
| 已作废       | （无）                         | 样品已作废，流程终止         |

## 技术栈

- **数据库**: SQLite3
- **报告生成**: openpyxl >= 3.1.2 (Excel), reportlab >= 4.0.8 (PDF)
- **打包工具**: PyInstaller >= 6.0.0
- **测试框架**: unittest (Python 内置)

## 业务规则

### 第一轮规则
1. **样品编号唯一性**: 系统会校验样品编号，重复编号禁止录入
2. **报告生成限制**: 所有检测项目完成后才能生成报告
3. **修改留痕**: 所有样品信息修改都会记录到审计日志
4. **删除确认**: 删除样品前会弹出确认对话框
5. **附件检测**: 打开附件管理时自动检测文件是否丢失
6. **状态约束**: 状态流转按照预设流程进行

### 第二轮新增规则
7. **状态流转严格校验**: 只能在预设的状态之间切换，非法切换自动拦截
8. **检测结果修改强制留痕**: 修改检测记录必须填写修改原因，所有变更永久记录
9. **附件路径完整性校验**: 上传前检查文件存在性、大小、类型
10. **附件丢失可恢复**: 附件文件丢失后可通过"重新绑定"功能关联新文件
11. **已作废状态不可逆转**: 标记为已作废的样品不能切换到任何其他状态

## 常见问题

### Q: 如何修改检测结果？
A: 在"检测记录"标签页中选择要修改的记录，点击"编辑"按钮，修改后必须填写修改原因。所有修改会被永久记录。

### Q: 附件文件丢失了怎么办？
A: 在"附件管理"对话框中，丢失的附件会显示红色标记。点击"重新绑定"按钮，选择新的文件即可重新关联。

### Q: 如何查看修改历史？
A: 点击"修改记录"标签页，可以查看所有检测结果的修改历史，包括修改人、修改时间、修改原因和具体变更内容。

### Q: 报告导出包含哪些内容？
A: 导出的报告包含：样品基础信息、检测项目及结果、状态流转记录、检测结果修改记录、附件清单五个完整部分。

### Q: 如何备份数据？
A: 点击菜单栏"数据管理" → "备份数据库"，选择备份位置即可。建议同时备份 `attachments/` 目录。

### Q: 数据库文件损坏怎么办？
A: 使用"数据管理" → "恢复数据库"功能，选择之前的备份文件进行恢复。

## 注意事项

1. 建议定期进行数据备份，建议每周至少备份一次
2. 附件文件请勿手动删除，否则系统会显示"文件丢失"
3. 数据库文件建议定期备份到外部存储设备
4. 修改检测结果请务必填写真实的修改原因，便于后续追溯
5. 样品状态变更请按照实际检测流程操作，确保数据准确性
6. 系统支持的附件预览格式：JPG、PNG、GIF、BMP、TXT、PDF

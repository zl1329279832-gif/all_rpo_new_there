# 智慧仓储管理系统 - 联调说明

## 1. 环境要求

### 1.1 后端环境
- JDK 1.8+
- Maven 3.6+
- MySQL 8.0+
- Redis 5.0+
- Node.js 16+

### 1.2 前端环境
- Node.js 16+
- npm 8+ 或 yarn 1.22+

---

## 2. 数据库初始化

### 2.1 创建数据库
```sql
CREATE DATABASE IF NOT EXISTS wms DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2.2 执行初始化脚本
```bash
# 进入后端项目目录
cd backend

# 执行SQL脚本（使用MySQL客户端）
mysql -u root -p wms < src/main/resources/sql/wms_init.sql
```

### 2.3 数据库连接配置
修改 `backend/src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/wms?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
  redis:
    host: localhost
    port: 6379
    password: your_redis_password
```

---

## 3. 后端启动

### 3.1 安装依赖
```bash
cd backend
mvn clean install -DskipTests
```

### 3.2 启动应用
```bash
# 方式一：Maven启动
mvn spring-boot:run

# 方式二：Jar启动
mvn clean package -DskipTests
java -jar target/wms-1.0.0.jar
```

### 3.3 验证启动
- 应用地址：http://localhost:8080
- 接口文档：http://localhost:8080/swagger-ui.html
- 健康检查：http://localhost:8080/api/health

---

## 4. 前端启动

### 4.1 安装依赖
```bash
cd frontend
npm install
# 或
yarn install
```

### 4.2 配置API地址
修改 `frontend/.env.development`：
```env
VITE_API_BASE_URL=http://localhost:8080/api
```

### 4.3 启动开发服务器
```bash
npm run dev
# 或
yarn dev
```

### 4.4 访问前端
- 前端地址：http://localhost:5173
- 默认账号：admin / 123456

## 5. 核心业务联调流程

### 5.1 入库流程
```
供应商到货 → 创建入库单 → 入库质检 → 库位分配 → 确认入库 → 批次库存更新
```

### 5.2 出库流程
```
创建出库单 → 库存锁定 → 生成拣货任务 → 拣货确认 → 出库复核 → 库存扣减
```

### 5.3 盘点流程
```
创建盘点单 → 库存冻结 → 录入盘点结果 → 差异计算 → 盘盈/盘亏处理
```

## 7. 常见问题

### 7.1 数据库连接失败
- 检查MySQL服务是否启动
- 确认数据库用户名密码是否正确
- 确认数据库已创建

### 7.2 Redis连接失败
- 检查Redis服务是否启动
- 确认Redis密码配置正确

### 7.3 跨域问题
- 后端已配置CORS，确保前端API地址配置正确
- 确认后端服务已正常启动

### 7.4 前端页面空白
- 清除浏览器缓存
- 检查控制台是否有错误信息
- 确认后端API服务可访问

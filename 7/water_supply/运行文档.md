# 城市供水管网运行分析系统 — 运行文档

## 环境要求

- Python 3.9+
- pip 包管理器

## 安装步骤

```bash
cd water_supply
pip install -r requirements.txt
```

## 项目结构

```
water_supply/
├── config.py           # 参数配置与验证
├── network.py          # 管网拓扑构建与连通性检查
├── hydraulic.py        # 水力计算（Hazen-Williams 求解器）
├── simulation.py       # 场景模拟（漏损/阀门/泵站故障）
├── metrics.py          # 分析指标（风险/不足/关键节点/韧性）
├── charts.py           # 结果可视化
├── export.py           # CSV 导出
├── app.py              # Streamlit 交互界面
├── data/
│   └── example_network.json   # 示例管网数据
├── tests/              # 单元测试
├── requirements.txt    # 依赖清单
├── .gitignore
├── 模型假设说明.md      # 模型假设与公式
└── 运行文档.md          # 本文档
```

## 运行方式

### 方式一：Streamlit 交互界面（推荐）

```bash
cd water_supply
streamlit run app.py
```

浏览器打开后可：
1. 在左侧加载示例数据或上传自定义 JSON
2. 调整最小压力、漏损系数等参数
3. 点击"运行水力计算"开始分析
4. 在各标签页查看压力分布、流量分布、场景模拟、风险排行等
5. 导出 CSV 结果

### 方式二：Python 脚本

```python
from config import load_config_from_json
from hydraulic import solve_network
from simulation import simulate_leakage, simulate_valve_closure
from metrics import compute_leakage_risk, identify_supply_shortage, rank_critical_nodes
from export import export_full_report

# 加载配置
config = load_config_from_json("data/example_network.json")

# 水力求解
result = solve_network(config)
print("收敛:", result.converged)
print("节点压力:", result.node_pressures)

# 漏损模拟
leak_result = simulate_leakage(config, leak_coefficient=1e-5)

# 阀门关闭模拟
valve_result = simulate_valve_closure(config, closed_pipe_ids=["P11"])

# 分析指标
risk = compute_leakage_risk(config, result)
shortage = identify_supply_shortage(config, result)
critical = rank_critical_nodes(config, result)

# 导出
export_full_report(config, result, filepath="simulation_results/full_report.csv")
```

### 方式三：运行测试

```bash
cd water_supply
python -m pytest tests/ -v
```

## 输入数据格式

JSON 文件结构如下：

```json
{
  "nodes": [
    {
      "node_id": "S1",
      "elevation": 50.0,
      "demand": 0.0,
      "is_source": true,
      "source_head": 80.0,
      "x": 0.0,
      "y": 5.0
    }
  ],
  "pipes": [
    {
      "pipe_id": "P1",
      "start_node": "S1",
      "end_node": "N1",
      "length": 800.0,
      "diameter": 0.40,
      "roughness": 130,
      "status": "open"
    }
  ],
  "pumps": [
    {
      "pump_id": "PU1",
      "node_id": "N4",
      "head_added": 15.0,
      "max_flow": 0.08
    }
  ],
  "valves": [
    {
      "valve_id": "V1",
      "pipe_id": "P11",
      "status": "open",
      "opening_ratio": 1.0
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| node_id | string | 是 | 节点唯一标识 |
| elevation | float | 否 | 地面标高 (m)，默认 0 |
| demand | float | 否 | 用水量 (m³/s)，默认 0 |
| is_source | bool | 否 | 是否为水源节点，默认 false |
| source_head | float | 水源必填 | 水源水头 (m) |
| x, y | float | 否 | 节点坐标（用于绘图） |
| pipe_id | string | 是 | 管段唯一标识 |
| start_node / end_node | string | 是 | 起止节点 ID |
| length | float | 是 | 管段长度 (m) |
| diameter | float | 是 | 管段内径 (m) |
| roughness | float | 否 | Hazen-Williams 粗糙系数，默认 130 |
| status | string | 否 | "open" 或 "closed"，默认 "open" |
| pump_id | string | 是 | 泵站唯一标识 |
| head_added | float | 是 | 泵站扬程 (m) |
| max_flow | float | 是 | 泵站最大流量 (m³/s) |
| valve_id | string | 是 | 阀门唯一标识 |
| opening_ratio | float | 否 | 开度比 (0,1]，默认 1.0 |

## 输出说明

系统输出包括：
- **节点压力**：各节点的水头和压力值 (m)
- **管段流量**：各管段的流量 (m³/s) 和流速 (m/s)
- **漏损风险评分**：0~1 之间，越高越危险
- **供水不足节点**：压力低于最小压力的节点列表
- **关键节点排行**：按重要性排序的前 N 个节点
- **韧性指数**：0~1 之间，越高越健壮

## 常见问题

1. **求解不收敛**：检查管网是否连通、水源水头是否合理、管径是否过小
2. **负压力**：表示该节点供水不足，可能需要增加水源水头或管径
3. **管网不连通**：关闭管段前需确保有关键路径冗余

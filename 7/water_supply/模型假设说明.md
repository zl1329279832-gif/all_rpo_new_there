# 城市供水管网运行分析系统 — 模型假设说明

## 1. 水力模型基础

### 1.1 管段水头损失计算
本系统采用 **Hazen-Williams 经验公式** 计算管段水头损失：

$$h_f = \frac{10.67 \cdot L \cdot Q^{1.852}}{C^{1.852} \cdot D^{4.87}}$$

其中：
- $h_f$ — 水头损失 (m)
- $L$ — 管段长度 (m)
- $Q$ — 管段流量 (m³/s)
- $C$ — Hazen-Williams 粗糙系数（典型值：新钢管 140、铸铁管 130、旧管 100 以下）
- $D$ — 管段内径 (m)

**假设**：该公式适用于常温清水、紊流充分发展的管道流动，在流速 0.6~3.0 m/s 范围内精度较好。

### 1.2 管网求解方法
采用**节点法**建立非线性方程组：
- 水源节点：已知水头（定水头节点）
- 需求节点：已知用水量（定流量节点）
- 对每个需求节点建立流量守恒方程：$\sum Q_{in} - \sum Q_{out} = D_i$
- 使用 SciPy `fsolve`（拟牛顿法）求解节点水头

**假设**：稳态流动，不考虑水锤和瞬变流效应。

## 2. 漏损模型

漏损流量与节点压力的关系采用幂律模型：

$$Q_{leak} = C_{leak} \cdot P^{\alpha}$$

其中：
- $Q_{leak}$ — 漏损流量 (m³/s)
- $C_{leak}$ — 漏损系数（取决于管道破损程度）
- $P$ — 节点压力 (m)
- $\alpha$ — 压力指数（通常取 0.5~1.0，默认 0.5）

**假设**：
- 漏损仅发生在需求节点
- 漏损流量叠加在节点需求之上
- 漏损系数对同一场景中所有漏损节点一致

## 3. 泵站模型

泵站简化为在指定节点处添加固定扬程：

$$H_{downstream} = H_{upstream} + H_{pump}$$

**假设**：
- 泵站扬程恒定，不考虑泵特性曲线
- 泵站流量不超过最大流量限制
- 泵站故障时扬程降为 0

## 4. 阀门模型

- **全开**：管段阻力不变
- **全关**：管段从管网中移除
- **部分开启**：管段阻力除以开度比的平方：$R_{eff} = R / \beta^2$，其中 $\beta \in (0, 1)$ 为开度比

**假设**：阀门部分开启的阻力模型为近似简化。

## 5. 压力与水头关系

节点压力 = 节点水头 - 节点标高

$$P_i = H_i - Z_i$$

其中 $Z_i$ 为节点 $i$ 的地面标高。负压力表示该节点可能出现空化或断流。

## 6. 风险与韧性指标

### 6.1 漏损风险评分
$$Risk = 0.4 \times R_{pressure} + 0.3 \times R_{velocity} + 0.3 \times R_{age}$$

- 压力风险：高压（>60m）0.8、中高压 0.5、正常 0.2、低压 0.1、负压 0.9
- 流速风险：>2.5 m/s 为 0.8、1.5~2.5 为 0.4、<1.5 为 0.1
- 管龄风险：>30年 1.5、20~30年 1.2、10~20年 1.0、<10年 0.8

### 6.2 供水不足判定
节点压力低于最小供水压力（默认 15m）即判定为供水不足。

### 6.3 关键节点评分
$$Criticality = 0.35 \times D_{importance} + 0.35 \times P_{vulnerability} + 0.30 \times B_{centrality}$$

- 需求重要性 = 节点需求 / 总需求
- 压力脆弱性 = 1 - min(节点压力/平均水源水头, 1)
- 连接度 = 介数中心性 (Betweenness Centrality)

### 6.4 韧性指数
$$Resilience = 0.4 \times A_{pressure} + 0.3 \times S_{surplus} + 0.3 \times R_{redundancy}$$

## 7. 模型局限性

1. **稳态假设**：不考虑管网动态变化和水力瞬变
2. **Hazen-Williams 适用范围**：对大管径、低流速管段精度下降
3. **泵站简化**：未考虑泵特性曲线和变速调节
4. **漏损模型**：漏损位置和程度为假设输入
5. **温度影响**：忽略水温对水密度和粘度的影响
6. **水质因素**：未考虑水质对管壁粗糙度的影响
